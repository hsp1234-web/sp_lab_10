# `utils`：共用工具程式目錄

本目錄 (`utils`) 用於存放專案中可被多個模組共用的輔助工具或腳本。這些工具通常不屬於核心的業務邏輯，但能有效提升開發效率或自動化重複性任務。

## 目錄結構

```
utils/
├── create_log.py     # 自動化建立開發日誌的腳本
└── README.md         # (本檔案) utils 目錄的說明
```

## 工具說明

-   **`create_log.py`**: 一個方便的指令行工具，可以自動：
    -   取得當前時間。
    -   生成符合 `docs/logs/` 目錄規範的標準化檔名。
    -   在對應的月份資料夾下，建立一個包含日誌模板的 Markdown 檔案。

    **使用方法:**
    ```bash
    python utils/create_log.py
    ```
