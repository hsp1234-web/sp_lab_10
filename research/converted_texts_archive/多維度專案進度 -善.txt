I. 專案願景與核心目標

核心目標： 建立一個評估美國股市在極短 (1-7天)、短期 (約 60 天)、中期 (約 160 天) 及長期 (約 10 年) 四個時間維度下量化風險的系統原型。

開發主軸： 以免費 API 和開源工具作為主要開發路徑。

設計彈性與現實考量： 框架需具備接入付費 API 的彈性，因為研究已確認，獲取可靠的、高頻的日內數據（對極短/短期風險評估尤其重要）必須使用付費數據源。

II. 風險維度、指標與數據挑戰

風險維度與概念指標：

極短 (1-7 天): 即時動態、事件風險、情緒動能 (例如：超短期波動率、事件衝擊評估)。

短期 (約 60 天): 波動性、尾部風險 (例如：預測波動率、CVaR)。

中期 (約 160 天): 趨勢、回撤風險 (例如：MDD 預測/概率)。

長期 (約 10 年): 宏觀週期、系統風險 (例如：宏觀調整波動率、系統風險概率)。

數據來源與核心挑戰 (研究確認)：

免費來源 (主用): FRED, yfinance, FMP (免費層), Finnhub (免費層), AV (免費層), News API (免費層) 等。

嚴峻限制： 免費 API 無法提供可靠的即時/高頻期貨、選擇權深度數據及日內利率變動；存在嚴格的請求限制、數據延遲、覆蓋不全、質量與穩定性風險 (尤其 yfinance)。

結論： 完全依賴免費 API 無法構建可靠的日內高頻風險系統，僅適用於日終分析、研究或中長週期評估。

技術應對： 數據緩存 (Caching)。

III. 系統框架設計藍圖

設計原則： 模組化、可配置、健壯、可擴展。

核心模組： 設定管理 (含 API 選擇/金鑰)、數據獲取與緩存 (含抽象層)、新聞/情緒處理、特徵工程、模型訓練/管理、風險預測、主控流程、結果輸出。

數據獲取抽象化： 設計通用接口，內部根據配置調用特定 API 的 Wrapper，為未來接入付費 API 保留彈性。

IV. 核心解決方案：互動式、分層、優化的處理流程 (針對免費 API 主軸)

為應對免費 API 限制，採用半自動化流程：

步驟 0：初步快速評估 (Quick Estimate):

目的： 即時、極粗略的四維度風險快照。

方法： 最少量/快取數據，簡易計算。

輸出： 初步風險標籤/指標 (低精度警告)。

步驟 1：呈現快速評估並詢問是否詳解:

詢問使用者是否繼續 (Enter/Y = Yes, N = No)。

目的： 獲取較全面的宏觀/市場背景。

執行： 調用 FRED, yfinance (注意風險)。

限制： 無法獲取可靠即時期貨/選擇權深度數據。

步驟 3：(若 Yes) 呈現第一層結果並進行優化互動:

目的： 引導使用者決定是否調用限制性 API。

目的： 獲取特定深度數據。

執行： 僅在使用者指示下調用 FMP, Finnhub, AV, News API 免費層。

步驟 5：(若 Yes) 最終整合與分析:

目的： 產生基於可用免費數據的最終風險評估。

# --- 定義緩存目錄 ---

CACHE_DIR = "data_cache"

if not os.path.exists(CACHE_DIR):

    try:

        os.makedirs(CACHE_DIR)

        print(f"已創建數據緩存目錄: {os.path.abspath(CACHE_DIR)}")

    except OSError as e:

        print(f"錯誤：創建緩存目錄 '{CACHE_DIR}' 失敗: {e}")

        # 如果無法創建目錄，後續緩存會失敗

else:

    print(f"數據緩存目錄: {os.path.abspath(CACHE_DIR)}")





def get_fred_series_with_cache(series_id: str,

                               api_key: str,

                               observation_start: str | None = None,

                               force_reload: bool = False

                               ) -> pd.Series | None:

    """

    獲取 FRED 數據序列，優先從本地 Parquet 緩存讀取，僅下載更新部分。

    包含詳細的打印信息和錯誤處理。

    """

    print(f"\n處理 FRED 序列: {series_id}...")

    # --- 前置檢查 ---

    if not api_key:

        print(f"  ! 錯誤：未提供 FRED API 金鑰。")

        return None

    if not fredapi_loaded:

        print(f"  ! 錯誤：fredapi 函式庫未載入。")

        return None

    can_use_cache = pyarrow_installed and os.path.exists(CACHE_DIR)

    if not can_use_cache and not force_reload:

        print(f"  ! 警告：無法使用 Parquet 緩存 (pyarrow未安裝或目錄創建失敗)。將嘗試直接下載。")

        force_reload = True # 強制直接下載



    cache_file_path = os.path.join(CACHE_DIR, f"fred_{series_id}.parquet")

    cached_data = None

    fetch_start_date = observation_start # API 請求的起始日期



    # --- 1. 嘗試從緩存加載 ---

    if not force_reload and can_use_cache:

        try:

            cached_data = pd.read_parquet(cache_file_path)

            print(f"  + 成功從緩存 '{os.path.basename(cache_file_path)}' 加載 {len(cached_data)} 筆數據。")

            if not cached_data.empty:

                last_cached_date = cached_data.index.max()

                # 從緩存最後記錄的下一天開始請求更新

                fetch_start_date_obj = last_cached_date + timedelta(days=1)

                fetch_start_date = fetch_start_date_obj.strftime('%Y-%m-%d')

                print(f"  + 緩存最新日期: {last_cached_date.strftime('%Y-%m-%d')}，將從 {fetch_start_date} 開始請求更新。")

            else:

                print(f"  + 緩存文件為空，將嘗試獲取所有數據。")

                fetch_start_date = observation_start # 緩存為空，按指定或默認起始日期

        except FileNotFoundError:

            print(f"  * 緩存文件 '{os.path.basename(cache_file_path)}' 不存在，將嘗試獲取數據。")

            fetch_start_date = observation_start

        except Exception as e:

            print(f"  ! 錯誤：讀取緩存 '{os.path.basename(cache_file_path)}' 失敗: {e}")

            traceback.print_exc()

            cached_data = None # 視為無緩存



    if force_reload:

         print(f"  * 強制重新加載，將獲取從 {observation_start or '最早'} 開始的所有數據。")

         fetch_start_date = observation_start

         cached_data = None # 清空，以便完全替換



    # --- 2. 調用 API 獲取新數據 (如果需要) ---

    new_data = None

    needs_fetch = True

    today_str = datetime.now().strftime('%Y-%m-%d')



    if fetch_start_date and fetch_start_date > today_str:

         print(f"  * 計算出的獲取開始日期 {fetch_start_date} 晚於今天，無需獲取更新。")

         needs_fetch = False



    if needs_fetch:

        print(f"  > 呼叫 FRED API (序列: {series_id}, 開始日期: {fetch_start_date or '最早'})...")

        try:

            start_time = time.time()

            fred = Fred(api_key=api_key)

            new_data = fred.get_series(series_id, observation_start=fetch_start_date)

            end_time = time.time()

            print(f"  > API 調用耗時: {end_time - start_time:.2f} 秒。")



            if new_data is not None and not new_data.empty:

                print(f"  + 成功從 API 獲取 {len(new_data)} 筆新數據。")

            elif new_data is not None: # API 返回空 Series

                 print(f"  * API 未返回 {fetch_start_date or '最早'} 之後的新數據。")

            # else: # fredapi 出錯會拋異常，在 except 中處理



        except Exception as e:

            print(f"  ! 錯誤：獲取 FRED 序列 {series_id} (從 {fetch_start_date or '最早'} 開始) 時發生 API 錯誤。")

            print(f"  ! 詳細錯誤: {e}")

            traceback.print_exc()

            new_data = None # 確保出錯時 new_data 為 None



    # --- 3. 合併數據 ---

    combined_data = None

    if new_data is not None and not new_data.empty:

        if cached_data is not None:

            # 合併：優先保留新數據的值（處理可能的重疊）

            combined_data = new_data.combine_first(cached_data)

            combined_data.sort_index(inplace=True)

            print(f"  + 已合併緩存與新數據，總計 {len(combined_data)} 筆。")

        else:

            combined_data = new_data

            print(f"  + 僅使用新獲取的數據，總計 {len(combined_data)} 筆。")

    elif cached_data is not None:

        combined_data = cached_data

        print(f"  * 無新數據獲取/API出錯，使用現有緩存數據，總計 {len(combined_data)} 筆。")

    else:

        print(f"  ! 警告：無緩存數據也未能獲取新數據，序列 {series_id} 無法提供。")

        return None # 關鍵：確保返回 None



    # --- 4. 保存到緩存 ---

    if can_use_cache and combined_data is not None and not combined_data.empty:

        try:

            combined_data.to_parquet(cache_file_path)

            print(f"  + 成功將數據保存到緩存 '{os.path.basename(cache_file_path)}'。")

        except Exception as e:

            print(f"  ! 錯誤：保存緩存 '{os.path.basename(cache_file_path)}' 失敗: {e}")

            traceback.print_exc()

    elif not can_use_cache:

         print(f"  * 跳過保存到 Parquet 緩存 (pyarrow 未安裝或目錄無法創建)。")



    return combined_data

    """獲取 FRED 數據序列，帶緩存 (Parquet) 和增量更新。"""

    safe_series_id = ''.join(c if c.isalnum() else '_' for c in series_id); cache_file_path = os.path.join(CACHE_DIR, f"fred_{safe_series_id}.parquet")

    if not force_reload and can_use_cache:
        try:
            cached_data = pd.read_parquet(cache_file_path).squeeze();

        except Exception as e: print(f"  ! FRED 錯誤：讀取緩存 '{os.path.basename(cache_file_path)}' 失敗: {e}"); cached_data = None
    if force_reload: fetch_start_date = observation_start; cached_data = None

    """獲取 yfinance 股票數據，帶緩存 (Parquet) 和增量更新。"""
    if not ticker: print(f"  ! yfinance 錯誤：未提供股票代碼。"); return None

    if not can_use_cache and not force_reload: print(f"  ! yfinance 警告：無法使用 Parquet 緩存 ({ticker})。將嘗試直接下載。"); force_reload = True
    safe_ticker = ''.join(c if c.isalnum() else '_' for c in ticker); cache_file_path = os.path.join(CACHE_DIR, f"yf_{safe_ticker}_{interval}.parquet")
    cached_data = None; fetch_start_date = start_date
    if not force_reload and can_use_cache:
        try:
            cached_data = pd.read_parquet(cache_file_path);
            if not isinstance(cached_data.index, pd.DatetimeIndex): cached_data.index = pd.to_datetime(cached_data.index)
            if not cached_data.empty: last_cached_date = cached_data.index.max(); fetch_start_date_obj = last_cached_date + timedelta(days=1 if interval == '1d' else 0); fetch_start_date = fetch_start_date_obj.strftime('%Y-%m-%d')
            else: fetch_start_date = start_date
        except FileNotFoundError: fetch_start_date = start_date
        except Exception as e: print(f"  ! yfinance 錯誤：讀取緩存 '{os.path.basename(cache_file_path)}' 失敗: {e}"); cached_data = None
    if force_reload: fetch_start_date = start_date; cached_data = None
    new_data = None; needs_fetch = True; today_dt = datetime.now(); effective_end_date = end_date or today_dt.strftime('%Y-%m-%d')
    try:
        start_dt = datetime.strptime(fetch_start_date, '%Y-%m-%d') if fetch_start_date else None; end_dt = datetime.strptime(effective_end_date, '%Y-%m-%d')
        if start_dt and start_dt > end_dt + timedelta(days=1): needs_fetch = False # Allow fetching today's data

        api_start = fetch_start_date; api_end = (datetime.strptime(effective_end_date, '%Y-%m-%d') + timedelta(days=1)).strftime('%Y-%m-%d') if effective_end_date else None # yf end is exclusive
        try:
            ticker_obj = yf.Ticker(ticker); new_data = ticker_obj.history(start=api_start, end=api_end, interval=interval, auto_adjust=False, repair=False) # repair=True can be slow/problematic
            if new_data is None or new_data.empty: new_data = None
            else:
                original_len = len(new_data); new_data.dropna(subset=['Open', 'High', 'Low', 'Close', 'Volume'], how='any', inplace=True)
                new_data = new_data[new_data['Volume'] > 0]; cleaned_len = len(new_data)
                if not isinstance(new_data.index, pd.DatetimeIndex): new_data.index = pd.to_datetime(new_data.index)
                # Ensure consistent timezone handling (e.g., make naive)
                if new_data.index.tz is not None: new_data.index = new_data.index.tz_localize(None)
                new_data = new_data[['Open', 'High', 'Low', 'Close', 'Adj Close', 'Volume']]
        except Exception as e: print(f"  ! yfinance 錯誤：API 獲取 {ticker} 失敗: {e}"); new_data = None
    combined_data = None
    if new_data is not None and not new_data.empty:
        if cached_data is not None and not cached_data.empty:
             # Ensure cache is also timezone naive before combining
            if cached_data.index.tz is not None: cached_data.index = cached_data.index.tz_localize(None)
            combined_data = cached_data.copy(); combined_data.update(new_data); new_index = new_data.index.difference(cached_data.index)
            if not new_index.empty: combined_data = pd.concat([combined_data, new_data.loc[new_index]])

            combined_data.sort_index(inplace=True);
        else: combined_data = new_data.copy();
    elif cached_data is not None and not cached_data.empty:
         if cached_data.index.tz is not None: cached_data.index = cached_data.index.tz_localize(None) # Ensure consistent TZ before return

# --- 5. 初步快速評估函數 ---
def generate_quick_estimate(dgs10_latest: float | None, vix_latest: float | None, spy_close_latest: float | None = None) -> dict:
    """根據最新的 DGS10 和 VIX 值，生成初步的四維度風險狀態。"""
    # (v0.3 code)
    estimate = {
        "極短期 (1-7天)": {"狀態": "數據不足", "理由": ""}, "短期 (~60天)": {"狀態": "數據不足", "理由": ""},
        "中期 (~160天)": {"狀態": "數據不足", "理由": ""}, "長期 (~10年)": {"狀態": "數據不足", "理由": ""}
    }
    # VIX Logic
    if vix_latest is not None:
        status = "數據不足"; reason = f"VIX = {vix_latest:.2f}. "
        if vix_latest < 20: status = "低"; reason += "VIX < 20，預期波動低。"
        elif vix_latest < 30: status = "中"; reason += "20 <= VIX < 30，預期波動溫和。"
        elif vix_latest < 40: status = "高"; reason += "30 <= VIX < 40，預期波動高，短期不確定性大。"
        else: status = "極高"; reason += "VIX >= 40，預期波動極高，短期風險極大。"
        estimate["極短期 (1-7天)"]["狀態"] = estimate["短期 (~60天)"]["狀態"] = status
        estimate["極短期 (1-7天)"]["理由"] = estimate["短期 (~60天)"]["理由"] = reason
    else: estimate["極短期 (1-7天)"]["理由"] = estimate["短期 (~60天)"]["理由"] = "缺少 VIX 數據。"
    # DGS10 Logic
    if dgs10_latest is not None:
        status = "數據不足"; reason = f"DGS10 = {dgs10_latest:.2f}%. "
        if dgs10_latest < 2.5: status = "低"; reason += "DGS10 < 2.5%，利率環境寬鬆。"
        elif dgs10_latest < 4.0: status = "中"; reason += "2.5% <= DGS10 < 4.0%，利率溫和。"
        elif dgs10_latest < 5.0: status = "偏高"; reason += "4.0% <= DGS10 < 5.0%，利率偏高，存緊縮/估值壓力。"
        else: status = "高"; reason += "DGS10 >= 5.0%，利率高位，宏觀壓力顯著。"
        estimate["中期 (~160天)"]["狀態"] = estimate["長期 (~10年)"]["狀態"] = status
        estimate["中期 (~160天)"]["理由"] = estimate["長期 (~10年)"]["理由"] = reason
    else: estimate["中期 (~160天)"]["理由"] = estimate["長期 (~10年)"]["理由"] = "缺少 DGS10 數據。"
    return estimate

# --- 6. 繪製風險儀表圖函數 ---
def plot_risk_gauges(estimate: dict,
                     dgs10_latest: float | None,
                     vix_latest: float | None):
    """根據快速評估結果和實際指標值，繪製四個獨立儀表圖 (移除狀態文字)。"""
    # (v0.9 code)
    if not plotly_installed:
        print("! Plotly 未安裝，無法繪製儀表圖。")
        return

    def map_vix_to_gauge(vix):
        if vix is None: return 0
        value = ((vix - 10) / (50 - 10)) * 100
        return max(0, min(100, value))
    def map_dgs10_to_gauge(dgs10):
        if dgs10 is None: return 0
        value = ((dgs10 - 1) / (6 - 1)) * 100
        return max(0, min(100, value))

    dimensions = list(estimate.keys())
    if len(dimensions) != 4:
        print("! 評估結果維度數量不為 4，無法繪製 2x2 網格。")
        return

    fig = make_subplots(
        rows=2, cols=2,
        specs=[[{'type': 'indicator'}, {'type': 'indicator'}],
               [{'type': 'indicator'}, {'type': 'indicator'}]],
        subplot_titles=(dimensions[0], dimensions[1], dimensions[2], dimensions[3]),

def get_fred_series_with_cache(series_id: str, api_key: str, observation_start: str | None = None, force_reload: bool = False) -> pd.Series | None:

    """獲取 FRED 數據序列，帶緩存 (Parquet) 和增量更新。"""

    if not api_key: print(f"  ! FRED 錯誤：未提供 API 金鑰 ({series_id})。"); return None

    if not fredapi_loaded: print(f"  ! FRED 錯誤：fredapi 函式庫未載入 ({series_id})。"); return None

    can_use_cache = pyarrow_installed and os.path.exists(CACHE_DIR)

    if not can_use_cache and not force_reload: print(f"  ! FRED 警告：無法使用 Parquet 緩存 ({series_id})。將嘗試直接下載。"); force_reload = True

    safe_series_id = ''.join(c if c.isalnum() else '_' for c in series_id); cache_file_path = os.path.join(CACHE_DIR, f"fred_{safe_series_id}.parquet")

    cached_data = None; fetch_start_date = observation_start

    if not force_reload and can_use_cache:

        try:

            df = pd.read_parquet(cache_file_path);

            if not isinstance(df.index, pd.DatetimeIndex): df.index = pd.to_datetime(df.index)

            cached_data = df.squeeze(axis=1) if df.shape[1] == 1 else df # Ensure it's a Series if single column

            if not isinstance(cached_data.index, pd.DatetimeIndex): cached_data.index = pd.to_datetime(cached_data.index)

        except FileNotFoundError: fetch_start_date = observation_start

        except Exception as e: print(f"  ! FRED 錯誤：讀取緩存 '{os.path.basename(cache_file_path)}' 失敗: {e}"); cached_data = None # Removed traceback for final version

    if isinstance(cached_data, pd.Series) and not cached_data.empty:

        last_cached_date = cached_data.index.max(); fetch_start_date_obj = last_cached_date + timedelta(days=1); fetch_start_date = fetch_start_date_obj.strftime('%Y-%m-%d')

    elif cached_data is None or (isinstance(cached_data, pd.Series) and cached_data.empty): fetch_start_date = observation_start

    if force_reload: fetch_start_date = observation_start; cached_data = None

    new_data = None; needs_fetch = True;

    try:

        if fetch_start_date and datetime.strptime(fetch_start_date, '%Y-%m-%d').date() > datetime.now().date(): needs_fetch = False # Check date part only

    except ValueError: fetch_start_date = None; needs_fetch = True

    if needs_fetch:

        try: fred = Fred(api_key=api_key); series_data = fred.get_series(series_id, observation_start=fetch_start_date); new_data = series_data

        except Exception as e: print(f"  ! FRED 錯誤：API 獲取 {series_id} 失敗: {e}"); new_data = None

    combined_data = None

    if new_data is not None and not new_data.empty:

        if isinstance(new_data, pd.DataFrame): new_data = new_data.squeeze(axis=1)

        if not isinstance(new_data.index, pd.DatetimeIndex): new_data.index = pd.to_datetime(new_data.index)

        if cached_data is not None and not cached_data.empty:

            if isinstance(cached_data, pd.DataFrame): cached_data = cached_data.squeeze(axis=1)

            if not isinstance(cached_data.index, pd.DatetimeIndex): cached_data.index = pd.to_datetime(cached_data.index)

            combined_data = cached_data.copy(); combined_data.update(new_data); new_index = new_data.index.difference(cached_data.index)

            if not new_index.empty: combined_data = pd.concat([combined_data, new_data.loc[new_index]])

            combined_data.sort_index(inplace=True);

        else: combined_data = new_data.copy();

    elif cached_data is not None and not cached_data.empty:

         if isinstance(cached_data, pd.DataFrame): cached_data = cached_data.squeeze(axis=1)

         if not isinstance(cached_data.index, pd.DatetimeIndex): cached_data.index = pd.to_datetime(cached_data.index)

         combined_data = cached_data.copy();

    else: print(f"  ! FRED 警告：序列 {series_id} 無法提供。"); return None

    if can_use_cache and combined_data is not None and not combined_data.empty:

        try: combined_data.to_frame(name=series_id if isinstance(series_id, str) else 'value').to_parquet(cache_file_path);

        except Exception as e: print(f"  ! FRED 錯誤：保存緩存 '{os.path.basename(cache_file_path)}' 失敗: {e}")

    if isinstance(combined_data, pd.DataFrame): combined_data = combined_data.squeeze(axis=1)

    return combined_data





def get_yfinance_data_with_cache(ticker: str, start_date: str | None = None, end_date: str | None = None, interval: str = '1d', force_reload: bool = False) -> pd.DataFrame | None:

    """獲取 yfinance 股票數據，帶緩存 (Parquet) 和增量更新。"""

    # (v1.1 code)

    if not ticker: print(f"  ! yfinance 錯誤：未提供股票代碼。"); return None

    if not yfinance_loaded: print(f"  ! yfinance 錯誤：yfinance 函式庫未載入。"); return None

    can_use_cache = pyarrow_installed and os.path.exists(CACHE_DIR)

    if not can_use_cache and not force_reload: print(f"  ! yfinance 警告：無法使用 Parquet 緩存 ({ticker})。將嘗試直接下載。"); force_reload = True

    safe_ticker = ''.join(c if c.isalnum() else '_' for c in ticker); cache_file_path = os.path.join(CACHE_DIR, f"yf_{safe_ticker}_{interval}.parquet")

    cached_data = None; fetch_start_date = start_date

    if not force_reload and can_use_cache:

        try: cached_data = pd.read_parquet(cache_file_path);

        except FileNotFoundError: fetch_start_date = start_date

        except Exception as e: print(f"  ! yfinance 錯誤：讀取緩存 '{os.path.basename(cache_file_path)}' 失敗: {e}"); cached_data = None

    if cached_data is not None and not isinstance(cached_data.index, pd.DatetimeIndex): cached_data.index = pd.to_datetime(cached_data.index)

    if cached_data is not None and not cached_data.empty: last_cached_date = cached_data.index.max(); fetch_start_date_obj = last_cached_date + timedelta(days=1 if interval == '1d' else 0); fetch_start_date = fetch_start_date_obj.strftime('%Y-%m-%d')

    elif cached_data is None or cached_data.empty: fetch_start_date = start_date

    if force_reload: fetch_start_date = start_date; cached_data = None

    new_data = None; needs_fetch = True; today_dt = datetime.now(); effective_end_date = end_date or today_dt.strftime('%Y-%m-%d')

    try:

        start_dt = datetime.strptime(fetch_start_date, '%Y-%m-%d').date() if fetch_start_date else None; end_dt = datetime.strptime(effective_end_date, '%Y-%m-%d').date()

        # Only fetch if start is on or before today

        if start_dt and start_dt > today_dt.date(): needs_fetch = False

    except ValueError: needs_fetch = True

    if needs_fetch:

        # Fetch up to tomorrow to ensure today's data is included if available

        api_start = fetch_start_date; api_end = (datetime.strptime(effective_end_date, '%Y-%m-%d') + timedelta(days=1)).strftime('%Y-%m-%d')

        try:

            ticker_obj = yf.Ticker(ticker); new_data = ticker_obj.history(start=api_start, end=api_end, interval=interval, auto_adjust=False, repair=False) # repair=True is often slow

            if new_data is None or new_data.empty: new_data = None

            else:

                # Basic cleaning

                new_data.dropna(subset=['Open', 'High', 'Low', 'Close', 'Volume'], how='any', inplace=True)

                new_data = new_data[new_data['Volume'] > 0]

                if not isinstance(new_data.index, pd.DatetimeIndex): new_data.index = pd.to_datetime(new_data.index)

                if new_data.index.tz is not None: new_data.index = new_data.index.tz_localize(None) # Make timezone naive

                new_data = new_data[['Open', 'High', 'Low', 'Close', 'Adj Close', 'Volume']]

        except Exception as e: print(f"  ! yfinance 錯誤：API 獲取 {ticker} 失敗: {e}"); new_data = None

    combined_data = None

    if new_data is not None and not new_data.empty:

        if cached_data is not None and not cached_data.empty:

            if cached_data.index.tz is not None: cached_data.index = cached_data.index.tz_localize(None) # Ensure cache is naive

            # Combine using concat and drop duplicates, keeping the latest

            combined_data = pd.concat([cached_data, new_data])

            combined_data = combined_data[~combined_data.index.duplicated(keep='last')]

            combined_data.sort_index(inplace=True);

        else: combined_data = new_data.copy();

    elif cached_data is not None and not cached_data.empty:

         if cached_data.index.tz is not None: cached_data.index = cached_data.index.tz_localize(None)

         combined_data = cached_data.copy();

    else: print(f"  ! yfinance 警告：標的 {ticker} 無法提供。"); return None

    if can_use_cache and combined_data is not None and not combined_data.empty:

        try: combined_data.to_parquet(cache_file_path);

        except Exception as e: print(f"  ! yfinance 錯誤：保存緩存 '{os.path.basename(cache_file_path)}' 失敗: {e}")

    return combined_data



# --- 5. 初步快速評估函數 ---

def generate_quick_estimate_v2(dgs10_data: pd.Series | None, vix_data: pd.Series | None, spy_close_latest: float | None = None, vix_up_thresh: float = 5.0, vix_down_thresh: float = 3.0, dgs10_up_thresh: float = 0.15, dgs10_down_thresh: float = 0.10) -> dict:

    """根據最新的 DGS10 和 VIX 值及其 5 日變化，生成初步的四維度風險狀態。"""

    # (v1.0 code) - Using Chinese Keys

    estimate = { "極短期 (1-7天)": {"狀態": "數據不足", "理由": ""}, "短期 (~60天)": {"狀態": "數據不足", "理由": ""}, "中期 (~160天)": {"狀態": "數據不足", "理由": ""}, "長期 (~10年)": {"狀態": "數據不足", "理由": ""} }

    change_period = 5

    vix_latest = None; vix_change_desc = ""

    if vix_data is not None and not vix_data.empty:

        try:

            vix_latest = vix_data.iloc[-1]

            if len(vix_data) >= change_period + 1:

                vix_5d_ago = vix_data.iloc[-(change_period + 1)]; vix_change_5d = vix_latest - vix_5d_ago

                if vix_change_5d > vix_up_thresh: vix_change_desc = f" (5日+{vix_change_5d:.2f} 快速上升)"

                elif vix_change_5d < -abs(vix_down_thresh): vix_change_desc = f" (5日{vix_change_5d:.2f} 明顯回落)"

        except Exception as e: print(f"! 計算 VIX 變化時出錯: {e}")

    if vix_latest is not None:

        status_base = "數據不足"; reason = f"VIX = {vix_latest:.2f}. "

        if vix_latest < 20: status_base = "低"; reason += "VIX < 20。"

        elif vix_latest < 30: status_base = "中"; reason += "20 <= VIX < 30。"

        elif vix_latest < 40: status_base = "高"; reason += "30 <= VIX < 40。"

        else: status_base = "極高"; reason += "VIX >= 40。"

        status = status_base + vix_change_desc if vix_change_desc else status_base

        estimate["極短期 (1-7天)"]["狀態"] = estimate["短期 (~60天)"]["狀態"] = status

        estimate["極短期 (1-7天)"]["理由"] = estimate["短期 (~60天)"]["理由"] = reason + vix_change_desc.replace('(','').replace(')','')

    else: estimate["極短期 (1-7天)"]["理由"] = estimate["短期 (~60天)"]["理由"] = "缺少 VIX 數據。"

    dgs10_latest = None; dgs10_change_desc = ""

    if dgs10_data is not None and not dgs10_data.empty:

         try:

             dgs10_latest = dgs10_data.iloc[-1]

             if len(dgs10_data) >= change_period + 1:

                 dgs10_5d_ago = dgs10_data.iloc[-(change_period + 1)]; dgs10_change_5d = dgs10_latest - dgs10_5d_ago

                 if dgs10_change_5d > dgs10_up_thresh: dgs10_change_desc = f" (5日+{dgs10_change_5d:.2f}% 快速上升)"

                 elif dgs10_change_5d < -abs(dgs10_down_thresh): dgs10_change_desc = f" (5日{dgs10_change_5d:.2f}% 明顯回落)"

         except Exception as e: print(f"! 計算 DGS10 變化時出錯: {e}")

    if dgs10_latest is not None:

        status_base = "數據不足"; reason = f"DGS10 = {dgs10_latest:.2f}%. "

        if dgs10_latest < 2.5: status_base = "低"; reason += "DGS10 < 2.5%。"

        elif dgs10_latest < 4.0: status_base = "中"; reason += "2.5% <= DGS10 < 4.0%。"

        elif dgs10_latest < 5.0: status_base = "偏高"; reason += "4.0% <= DGS10 < 5.0%。"

        else: status_base = "高"; reason += "DGS10 >= 5.0%。"

        status = status_base + dgs10_change_desc if dgs10_change_desc else status_base

        estimate["中期 (~160天)"]["狀態"] = estimate["長期 (~10年)"]["狀態"] = status

        estimate["中期 (~160天)"]["理由"] = estimate["長期 (~10年)"]["理由"] = reason + dgs10_change_desc.replace('(','').replace(')','')

    else: estimate["中期 (~160天)"]["理由"] = estimate["長期 (~10年)"]["理由"] = "缺少 DGS10 數據。"

    return estimate

def calculate_sma(series: pd.Series, period: int) -> pd.Series:

    if not isinstance(series, pd.Series): return pd.Series(dtype=float)

    if period <= 0 or not isinstance(period, int): return pd.Series(index=series.index, dtype=float)

    return series.rolling(window=period, min_periods=max(1, period//2)).mean()



def calculate_atr(df_ohlc: pd.DataFrame, period: int = 14) -> pd.Series:

    if not isinstance(df_ohlc, pd.DataFrame) or not all(col in df_ohlc.columns for col in ['High', 'Low', 'Close']): print("! ATR 計算錯誤: 輸入非 DataFrame 或缺少 HLC 列。"); return pd.Series(dtype=float)

    if period <= 0 or not isinstance(period, int): return pd.Series(index=df_ohlc.index, dtype=float)

    df = df_ohlc.copy()

    df['h-l'] = df['High'] - df['Low']; df['h-pc'] = np.abs(df['High'] - df['Close'].shift(1)); df['l-pc'] = np.abs(df['Low'] - df['Close'].shift(1))

    df['tr'] = df[['h-l', 'h-pc', 'l-pc']].max(axis=1); atr = df['tr'].rolling(window=period, min_periods=1).mean()

    return atr



def calculate_deviation_pct(series1: pd.Series, series2: pd.Series) -> pd.Series:

    if not isinstance(series1, pd.Series) or not isinstance(series2, pd.Series): return pd.Series(dtype=float)

    s1_aligned, s2_aligned = series1.align(series2, join='inner');

    if s1_aligned.empty: return pd.Series(dtype=float)

    denominator = s2_aligned.replace(0, np.nan); deviation = (s1_aligned - s2_aligned) / denominator * 100

    return deviation



def get_percentile_rank(series: pd.Series, value: float) -> float | None:

    if not isinstance(series, pd.Series) or series.dropna().empty or value is None or not np.isfinite(value): return None

    if not scipy_loaded: print("! Scipy 未載入，無法計算百分位。"); return None

    try: return percentileofscore(series.dropna(), value, kind='weak') # Use 'weak' for <=

    except Exception as e: print(f"! 計算百分位時出錯: {e}"); return None

def generate_basic_quick_estimate(dgs10_data: pd.Series | None,

                                  vix_data: pd.Series | None,

                                  change_period: int = 5,

                                  # *** 新增參數 ***

                                  vix_thresh_up: float = 5.0,

                                  vix_thresh_down: float = 3.0,

                                  dgs10_thresh_up: float = 0.15,

                                  dgs10_thresh_down: float = 0.10

                                 ) -> dict:

    """

    計算基於 VIX 和 DGS10 最新值及其 N 日變化的基本快速評估。

    返回包含狀態、理由和儀表映射值的字典。

    """

    estimate = {

        "極短期 (1-7天)": {"狀態": "數據不足", "理由": "", "gauge_value": 0.0},

        "短期 (~60天)":  {"狀態": "數據不足", "理由": "", "gauge_value": 0.0},

        "中期 (~160天)": {"狀態": "數據不足", "理由": "", "gauge_value": 0.0},

        "長期 (~10年)":  {"狀態": "數據不足", "理由": "", "gauge_value": 0.0}

    }

    if not numpy_loaded: return estimate



    def map_vix_to_gauge(vix):

        if vix is None or not np.isfinite(vix): return 0.0

        value = ((vix - 10) / (50 - 10)) * 100

        return np.clip(value, 0, 100)



    def map_dgs10_to_gauge(dgs10):

        if dgs10 is None or not np.isfinite(dgs10): return 0.0

        value = ((dgs10 - 1) / (6 - 1)) * 100

        return np.clip(value, 0, 100)



    # --- VIX 評估 ---

    vix_latest = None; vix_change_desc = ""

    if vix_data is not None and not vix_data.empty:

        try:

            vix_latest = vix_data.iloc[-1] if not vix_data.empty else None

            if len(vix_data) >= change_period + 1:

                vix_change_nd = vix_latest - vix_data.iloc[-(change_period + 1)]

                # *** 使用傳入的參數 ***

                if vix_change_nd > vix_thresh_up: vix_change_desc = f" ({change_period}日+{vix_change_nd:.2f} 快速上升)"

                elif vix_change_nd < -abs(vix_thresh_down): vix_change_desc = f" ({change_period}日{vix_change_nd:.2f} 明顯回落)"

        except Exception as e: print(f"! 計算 VIX 變化時出錯: {e}") # 錯誤已被捕獲



    gauge_val_vix = 0.0 # 初始化

    if vix_latest is not None and np.isfinite(vix_latest):

        status_base = "數據不足"; reason = f"VIX = {vix_latest:.2f}. "

        if vix_latest < 20: status_base = "低"; reason += "VIX < 20。"

        elif vix_latest < 30: status_base = "中"; reason += "20 <= VIX < 30。"

        elif vix_latest < 40: status_base = "高"; reason += "30 <= VIX < 40。"

        else: status_base = "極高"; reason += "VIX >= 40。"

        status = status_base + vix_change_desc if vix_change_desc else status_base

        gauge_val_vix = map_vix_to_gauge(vix_latest) # 計算 gauge value

        reason_combined = reason.strip() + vix_change_desc.replace('(','').replace(')','')

        estimate["極短期 (1-7天)"] = {"狀態": status, "理由": reason_combined, "gauge_value": gauge_val_vix}

        estimate["短期 (~60天)"] = {"狀態": status, "理由": reason_combined, "gauge_value": gauge_val_vix}

    else:

        estimate["極短期 (1-7天)"]["理由"] = "缺少 VIX 數據。"

        estimate["短期 (~60天)"]["理由"] = "缺少 VIX 數據。"



    # --- DGS10 評估 ---

    dgs10_latest = None; dgs10_change_desc = ""

    if dgs10_data is not None and not dgs10_data.empty:

         try:

             dgs10_latest = dgs10_data.iloc[-1] if not dgs10_data.empty else None

             if len(dgs10_data) >= change_period + 1:

                 dgs10_change_nd = dgs10_latest - dgs10_data.iloc[-(change_period + 1)]

                 # *** 使用傳入的參數 ***

                 if dgs10_change_nd > dgs10_thresh_up: dgs10_change_desc = f" ({change_period}日+{dgs10_change_nd:.2f}% 快速上升)"

                 elif dgs10_change_nd < -abs(dgs10_thresh_down): dgs10_change_desc = f" ({change_period}日{dgs10_change_nd:.2f}% 明顯回落)"

         except Exception as e: print(f"! 計算 DGS10 變化時出錯: {e}") # 錯誤已被捕獲



    gauge_val_dgs10 = 0.0 # 初始化

    if dgs10_latest is not None and np.isfinite(dgs10_latest):

        status_base = "數據不足"; reason = f"DGS10 = {dgs10_latest:.2f}%. "

        if dgs10_latest < 2.5: status_base = "低"; reason += "DGS10 < 2.5%。"

        elif dgs10_latest < 4.0: status_base = "中"; reason += "2.5% <= DGS10 < 4.0%。"

        elif dgs10_latest < 5.0: status_base = "偏高"; reason += "4.0% <= DGS10 < 5.0%。"

        else: status_base = "高"; reason += "DGS10 >= 5.0%。"

        status = status_base + dgs10_change_desc if dgs10_change_desc else status_base

        gauge_val_dgs10 = map_dgs10_to_gauge(dgs10_latest) # 計算 gauge value

        reason_combined = reason.strip() + dgs10_change_desc.replace('(','').replace(')','')

        estimate["中期 (~160天)"] = {"狀態": status, "理由": reason_combined, "gauge_value": gauge_val_dgs10}

        estimate["長期 (~10年)"] = {"狀態": status, "理由": reason_combined, "gauge_value": gauge_val_dgs10}

    else:

        estimate["中期 (~160天)"]["理由"] = "缺少 DGS10 數據。"

        estimate["長期 (~10年)"]["理由"] = "缺少 DGS10 數據。"



    # 確保即使出錯也有預設 gauge value

    if estimate["極短期 (1-7天)"]["gauge_value"] is None: estimate["極短期 (1-7天)"]["gauge_value"] = 0.0

    if estimate["短期 (~60天)"]["gauge_value"] is None: estimate["短期 (~60天)"]["gauge_value"] = 0.0

    if estimate["中期 (~160天)"]["gauge_value"] is None: estimate["中期 (~160天)"]["gauge_value"] = 0.0

    if estimate["長期 (~10年)"]["gauge_value"] is None: estimate["長期 (~10年)"]["gauge_value"] = 0.0





    return estimate

# --- 8. 核心風險計算邏輯 (進階分析) ---

def calculate_adaptive_deviation_risk_hist( ixic_hourly_data: pd.DataFrame | None, atr_period: int = 14, s1_short_ma_min: int = 1, s1_short_ma_max: int = 20, s1_long_ma_min: int = 40, s1_long_ma_max: int = 150, s1_deviation_lookback_hours: int = 90 * 7, hist_calculation_scheme: int = 1, hist_chart_hours: int = 90 * 7 ) -> tuple[dict | None, pd.Series | None]:

    # (v1.6 code with robustness)

    min_required_len = max(s1_long_ma_max, 100, atr_period, s1_deviation_lookback_hours) + 5

    if ixic_hourly_data is None or ixic_hourly_data.empty or len(ixic_hourly_data) < min_required_len: print(f"! 風險計算錯誤：指數小時數據不足 {min_required_len} 條或缺失。"); return None, None

    if not all(col in ixic_hourly_data.columns for col in ['High', 'Low', 'Close', 'Adj Close']): print("! 風險計算錯誤：指數數據缺少 HLC 或 Adj Close 列。"); return None, None

    if not numpy_loaded or not scipy_loaded: print("! 風險計算錯誤：缺少 Numpy 或 Scipy。"); return None, None

    print("\n--- 開始計算波動率和歷史分佈 (需要時間) ---")

    price_series = ixic_hourly_data['Adj Close']

    atr = calculate_atr(ixic_hourly_data, period=atr_period); normalized_atr = (atr / price_series) * 100; normalized_atr.dropna(inplace=True)

    if normalized_atr.empty: print("! 無法計算標準化 ATR。"); return None, None

    long_term_median_atr = None; atr_p01 = None; atr_p99 = None

    try: long_term_median_atr = normalized_atr.median()

    except Exception as e: print(f"! 計算 ATR 中位數失敗: {e}")

    try: atr_p01 = normalized_atr.quantile(0.01); atr_p99 = normalized_atr.quantile(0.99)

    except Exception as e: print(f"! 計算 ATR 百分位失敗: {e}")

    if long_term_median_atr is None or atr_p01 is None or atr_p99 is None: print("! 無法完成 ATR 歷史分佈計算。"); return None, None

    print(f"  長期標準化 ATR({atr_period}h) 中位數: {long_term_median_atr:.4f}%"); print(f"  用於映射的 ATR 範圍 (1%-99%): {atr_p01:.4f}% - {atr_p99:.4f}%")

    latest_norm_atr = normalized_atr.iloc[-1]; print(f"  最新標準化 ATR({atr_period}h): {latest_norm_atr:.4f}%")

    risk_score_series = pd.Series(index=ixic_hourly_data.index, dtype=float)

    latest_results = {"scheme": hist_calculation_scheme, "short_ma": 0, "long_ma": 0, "deviation": np.nan, "risk_score": np.nan}

    if hist_calculation_scheme == 2:

        # --- 方案二歷史計算 ---

        print("\n--- 計算方案二歷史風險值 (推薦組合 + 長期歷史百分位) ---")

        print("  預計算 5/50 和 10/100 乖離率序列..."); sma5 = calculate_sma(price_series, 5); sma50 = calculate_sma(price_series, 50); sma10 = calculate_sma(price_series, 10); sma100 = calculate_sma(price_series, 100)

        dev_5_50 = calculate_deviation_pct(sma5, sma50).dropna(); dev_10_100 = calculate_deviation_pct(sma10, sma100).dropna(); print("  預計算完成。")

        # Calculate over the period needed for the chart + buffer? Or full history? Let's use full history for percentile.

        target_index = normalized_atr.index # Use full index where ATR is available

        print(f"  開始計算 {len(target_index)} 個時間點的風險值...")

        for idx in target_index: # This loop can be slow

            current_atr = normalized_atr.loc[idx];

            if pd.isna(current_atr): continue

            if current_atr > long_term_median_atr: short_ma_hist, long_ma_hist = 5, 50; hist_dev_series = dev_5_50

            else: short_ma_hist, long_ma_hist = 10, 100; hist_dev_series = dev_10_100

            current_dev = hist_dev_series.get(idx, np.nan) # Use get for safety

            if pd.isna(current_dev): continue

            rank = get_percentile_rank(hist_dev_series, current_dev)

            if rank is not None: risk_score_series.loc[idx] = rank

            if idx == target_index[-1]: latest_results['short_ma'] = short_ma_hist; latest_results['long_ma'] = long_ma_hist; latest_results['deviation'] = current_dev; latest_results['risk_score'] = rank if rank is not None else np.nan

        print(f"  方案二歷史風險值計算完成。")

    else:

        # --- 方案一歷史計算 ---

        print("\n--- 計算方案一歷史風險值 (動態均線[用戶確認] + 近期範圍) ---")

        atr_percentile = np.clip((latest_norm_atr - atr_p01) / (atr_p99 - atr_p01 + 1e-9), 0, 1)

        suggested_short_ma = int(np.round(s1_short_ma_max - atr_percentile * (s1_short_ma_max - s1_short_ma_min))); suggested_long_ma = int(np.round(s1_long_ma_max - atr_percentile * (s1_long_ma_max - s1_long_ma_min)))

        print(f"  根據最新 ATR 百分位 ({atr_percentile*100:.1f}%), 建議均線組合: {suggested_short_ma}h / {suggested_long_ma}h")

             while True:

        deviation_latest = deviation_series.iloc[-1]; latest_results['deviation'] = deviation_latest

# --- 10. 繪製歷史風險趨勢圖函數 (帶平滑) ---

def plot_historical_risk_trend(risk_score_series: pd.Series | None, title: str, smoothing_period: int = 10, thresholds: list[float] = [25, 50, 75], figure_width: int = 800, figure_height: int = 450) -> go.Figure | None:

    """繪製顏色變化的歷史風險分數趨勢圖 (帶移動平均平滑)"""

    # (v1.7 code with smoothing)

    if not plotly_installed: print("! Plotly 未安裝。"); return None

    if risk_score_series is None or risk_score_series.dropna().empty:

        print("! 無歷史風險分數數據可供繪圖。")

        fig = go.Figure(); fig.add_annotation(text="歷史風險數據不足", xref="paper", yref="paper", showarrow=False, font={"size": 16}); fig.update_layout(width=figure_width, height=figure_height, title_text=title); return fig

    if smoothing_period > 0 and isinstance(smoothing_period, int) and len(risk_score_series.dropna()) >= smoothing_period :

        plot_series = risk_score_series.rolling(window=smoothing_period, min_periods=smoothing_period // 2).mean().dropna()

        print(f"  已對歷史風險值應用 {smoothing_period} 小時移動平均。")

    else:

        plot_series = risk_score_series.dropna()

        if smoothing_period > 0: print(f"  數據點不足 {smoothing_period}，未應用移動平均平滑。")

        else: print("  未應用移動平均平滑。")

    if plot_series.empty: print("! 平滑後無數據可供繪圖。"); return None

    fig = go.Figure()

    colors = ['rgba(0, 255, 0, 0.7)', 'rgba(255, 255, 0, 0.7)', 'rgba(255, 165, 0, 0.7)', 'rgba(255, 0, 0, 0.7)']

    bounds = [-np.inf, thresholds[0], thresholds[1], thresholds[2], np.inf]

    names = ['低風險 (0-25)', '中低風險 (25-50)', '中高風險 (50-75)', '高風險 (75-100)']

    # More robust way to plot segments

    x_all = plot_series.index

    y_all = plot_series.values

    for i in range(len(bounds) - 1):

        lower = bounds[i]; upper = bounds[i+1]

        indices = np.where((y_all >= lower) & (y_all < upper))[0]

        if len(indices) == 0: continue

        # Find contiguous segments

        splits = np.where(np.diff(indices) != 1)[0] + 1

        segments = np.split(indices, splits)

        first_segment = True # Flag to add legend only once per color

        for segment_indices in segments:

            if len(segment_indices) > 0:

                 # Add boundary points for better connection visualization (optional)

                 start_idx = segment_indices[0]

                 end_idx = segment_indices[-1]

                 plot_indices = segment_indices

                 if start_idx > 0:

                     plot_indices = np.insert(plot_indices, 0, start_idx - 1)

                 if end_idx < len(x_all) - 1:

                     plot_indices = np.append(plot_indices, end_idx + 1)

                 # Ensure indices are unique and sorted

                 plot_indices = np.unique(plot_indices)



                 # Get data for plotting this segment

                 x_segment = x_all[plot_indices]

                 y_segment = np.where(((y_all[plot_indices] >= lower) & (y_all[plot_indices] < upper)), y_all[plot_indices], np.nan) # Use NaN for points outside range



                 fig.add_trace(go.Scatter( x=x_segment, y=y_segment, mode='lines', line=dict(color=colors[i], width=2),

                                           name=names[i] if first_segment else None, # Show legend only once

                                           showlegend=first_segment, connectgaps=False ))

                 first_segment = False # Only show legend for the first segment of this color



    for threshold in thresholds: fig.add_hline(y=threshold, line_dash="dash", line_color="grey", annotation_text=f"{threshold}", annotation_position="bottom right")

    fig.update_layout( title=title, xaxis_title="日期 / 時間", yaxis_title=f"平滑風險值 (0-100, {smoothing_period}h MA)", yaxis_range=[-5, 105],

                       legend_title_text='風險區間', width=figure_width, height=figure_height, margin=dict(l=50, r=20, t=70, b=50) )

    return fig
