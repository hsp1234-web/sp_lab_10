綜合金融風險儀表板 - 專案狀態總結報告 (v1.0)

生成時間: 2025-05-06 06:40:00 Asia/Taipei (UTC+8)

整體狀態: ✅ 開發進行中 - 基礎數據獲取完成 (Development In Progress - Base Data Acquisition Complete)

核心功能:

整合多維度金融數據 (市場、宏觀、交易商部位等)。

計算量化風險指標。

評估綜合金融市場風險位階 (包含新台幣匯率作為觀察面向之一)。

以清晰、互動的儀表板視覺化呈現風險狀況與關鍵驅動因素。

專案目標:

目標 1 (階段一): 在 Google Colab 環境中，開發一個可運行的儀表板原型 (v1.0)，實現核心數據流、基礎風險評估和靜態視覺化 (兩段式 HTML：總覽表格 + 詳細卡片)。

目標 2 (階段二): 實現進階指標計算和風險評估邏輯，並加入互動式圖表。

目標 3 (階段三): 建立回測框架以驗證風險評估邏輯的有效性。

(ℹ️ 目標的可衡量指標將在開發過程中進一步細化。)

關鍵決策、假設與理由:

決策: 選擇 Google Colab 作為主要開發環境。

理由: 便於快速原型設計、整合 Python 生態系、利用免費計算資源、易於與 AI 協作。 (來源: 先前規劃)

決策: 採用模組化 Colab 儲存格設計，遵循 v3.4 設計準則。

理由: 提高程式碼可讀性、可維護性、可測試性，強制執行前置規劃與安全規範。 (來源: 本次開發過程)

決策: 最終儀表板採用兩段式佈局 (總覽表格 + 詳細卡片)。

理由: 平衡快速掃描與詳細信息獲取需求。 (來源: 先前規劃)

決策: 優先使用 Colab Secrets 管理 API 金鑰，並遵循 UPPER_CASE_WITH_UNDERSCORES 命名規則。

理由: 遵循 v3.4 安全規範，確保金鑰安全。 (來源: 本次開發過程)

決策: 使用 FRED 的 INDPRO (工業生產指數) 作為 ISM 製造業 PMI 的代理指標。

理由: 經研究確認 FRED 不再提供官方 ISM PMI 數據，INDPRO 是可用的相關替代指標。 (來源: 本次開發過程)

決策: 調整 Cell 1 程式碼結構 (移動 logger 初始化、增強檢查) 以解決 NameError。

理由: 確保 Cell 1 初始化流程的穩定性，解決先前遇到的全域變數未定義問題。 (來源: 本次除錯過程)

假設: 選定的 API (yfinance, Alpha Vantage (免費功能), FRED) 能提供足夠的歷史數據用於第一階段分析。

影響: 若數據質量或長度不足，可能影響後續指標計算和風險評估。

假設: 開發者具備必要的 Python, Pandas 及金融知識。

影響: 若技能不足，開發進度可能延遲。

Python 版本: (待 Cell 1 最終確認，預計 3.x)

關鍵函式庫: pandas, numpy, requests, requests-cache, yfinance, fredapi, tenacity, plotly, ipywidgets, openpyxl, pytz, logging (已在 Cell 1 中安裝/確認)

硬體加速器: 無特別需求 (預設 Colab 環境)

外部數據源: yfinance API, Alpha Vantage API (免費), FRED API, NY Fed 網站 (Excel 文件), Google Colab Secrets
