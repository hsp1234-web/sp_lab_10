## 🔍 策略問題診斷

### 主要問題識別

#### 1. 交易頻率過高
- **問題**：970個交易信號，平均每月16.4個
- **影響**：增加交易成本，降低淨報酬
- **建議**：增加信號過濾條件，降低至每月2-3個

#### 2. 平均報酬為負
- **問題**：月平均報酬-0.26%，未能實現正報酬
- **原因**：配對交易的均值回歸假設在強勢行情中失效
- **建議**：加入市場狀態識別，避免在單邊行情中交易

#### 3. 季度目標差距大
- **問題**：季度正報酬率遠低於75%目標
- **原因**：缺乏有效的季度風險控制機制
- **建議**：實現季度動態調整，熊市完全避險

### 技術問題

#### 1. 信號品質問題
- **Z分數計算**：60天窗口可能過短，信號不穩定
- **進出場時機**：退出條件過於寬鬆
- **市場適應性**：不同市場環境需要不同參數

#### 2. 倉位管理問題
- **固定倉位**：沒有根據市場波動調整倉位
- **風險控制**：月度MDD控制雖達成，但可以更精細

#### 3. 策略組合問題
- **現金比例**：60%過高，降低回報潛力
- **配對交易**：30%比例在弱勢環境下過高
- **選擇權保護**：10%完全沒有使用

#### 市場狀態識別
```python
def identify_market_state(price_series):
    """識別市場狀態"""
    # 計算趨勢指標
    sma_20 = price_series.rolling(20).mean()
    sma_60 = price_series.rolling(60).mean()

    current_price = price_series.iloc[-1]
    trend_20 = (current_price - sma_20.iloc[-1]) / sma_20.iloc[-1]
    trend_60 = (current_price - sma_60.iloc[-1]) / sma_60.iloc[-1]

    if trend_20 > 0.05 and trend_60 > 0.08:
        return "strong_bull"
    elif trend_20 < -0.05 and trend_60 < -0.08:
        return "strong_bear"
    else:
        return "neutral"
```

def quarterly_target_tracking(current_quarter_return, target_return=0.03):
    """季度目標追蹤"""
    remaining_months = 3 - (datetime.now().month - 1) % 3

    if remaining_months > 0:
        required_monthly = (target_return - current_quarter_return) / remaining_months
        return max(required_monthly, -0.02)  # 每月至少不虧損超過2%
    else:
        return 0
