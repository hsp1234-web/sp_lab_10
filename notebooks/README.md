# `notebooks`：Jupyter Notebooks 實驗區

本目錄 (`notebooks`) 用於存放所有的 Jupyter Notebooks (`.ipynb` 檔案)。這些 notebooks 是進行探索性數據分析 (Exploratory Data Analysis, EDA)、策略原型設計、以及視覺化研究的理想環境。

## 主要用途

-   **快速原型驗證**: 在將策略完整地整合進 `src` 之前，先在此處進行小規模的實驗與驗證。
-   **數據探索**: 對新的數據源或特徵進行視覺化與統計分析。
-   **教學與展示**: 建立可用於教學或展示特定功能的互動式筆記本。

## Colab 整合

本專案根目錄的 `README.md` 中提到了一個 `sp_lab.ipynb`，這是一個設計用於在 Google Colab 環境中一鍵執行的 notebook。這類用於部署或分享的 notebook 也屬於此目錄的管理範疇。
