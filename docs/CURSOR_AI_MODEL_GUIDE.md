### 實際計算範例

假設要完成一個「雙均線策略」的開發：

#### 方案 A：使用 Claude Opus（大模型）
```
任務：寫策略邏輯 + Debug + 優化
預估請求：3 次
成本：3 × $0.10 = $0.30
時間：15 分鐘
```

#### 方案 B：使用 DeepSeek V3.1（小模型）
```
任務：寫策略邏輯 + Debug + 優化
預估請求：5 次（可能需要修正 1-2 次錯誤）
成本：5 × $0.02 = $0.10
時間：25 分鐘
```

#### 結論
- **省錢優先**：選方案 B，省 67% 成本，多花 10 分鐘
- **省時優先**：選方案 A，多花 $0.20，省 10 分鐘
- **最佳平衡**：混合使用（見下方策略）

## 📊 總結：最佳實踐

### ✅ 應該做的
1. 用 DeepSeek V3.1 / Kimi K2 作為日常主力
