# Project Structure

This document outlines the high-level structure of the `sp_lab_v9` project and the purpose of each directory.

> [!IMPORTANT]
> **Source of Truth**: The `src/` directory is the ONLY location for source code. Do not create scripts in the root directory.

## Root Directory
- `log.md`: Development log and notes.
- `AGENTS.md`: Documentation about AI agents used in this project.
- `README.md`: General project introduction.
- `main.py`: Main entry point for the application.

## Source Code (`src/`)
Core application logic and scripts.
- `strategies/`: Quantitative trading strategy implementations.
- `data/`: Data acquisition and processing scripts.
- `backtest/`: Backtesting engine and performance analysis tools.
- `main.py`: Internal orchestration logic.

## Output (`output/`)
Unified directory for all generated artifacts.
- `results/`: Output files from backtests (CSV reports, charts).
- `logs/`: Execution logs generated by the system.
- `archive/`: Old scripts, temporary files, and deprecated code.

## Configuration (`config/`)
- `requirements.txt`: Python dependency requirements.

## Notebooks (`notebooks/`)
- Jupyter notebooks for interactive research and analysis.

## Utilities (`utils/`)
Helper scripts for maintenance and diagnostics.

## Data (`data/`)
- `raw/`: Raw data downloaded from external sources.
- `processed/`: Cleaned and merged datasets.

## Documentation (`docs/`)
- `PROJECT_STRUCTURE.md`: This file.
- Project documentation, plans, and proposals.
- **`logs/`**: 結構化開發日誌系統
    - 按月份分類存放（例如 `2025-11/`）
    - 每個日誌都是獨立的 Markdown 檔案
    - 檔名格式：`YYYY-MM-DD_HH-MM_description.md`
    - 使用 `python utils/create_log.py` 建立新日誌
