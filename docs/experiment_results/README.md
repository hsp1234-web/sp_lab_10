# 實驗結果歸檔：SMA 濾網策略分析

本目錄收錄了「月度持有策略」及其 SMA 濾網變體在不同市場（SPY、台指期）下的回測實驗結果、設定檔與分析總結。

## 文件索引

1.  **`spy_monthly_buy_hold_report.md`**
    *   **內容**：SPY 市場的「月度持有」策略（無 SMA 濾網）回測報告。
    *   **用途**：作為一個基準，展示了在一個長期多頭市場中，此策略的基礎表現。

2.  **`taifex_monthly_buy_hold_with_sma_report.md`**
    *   **內容**：台指期 (TX) 市場的「月度持有 + SMA 濾網」策略回測報告。
    *   **用途**：展示了策略在一個高波動性市場下的表現，並凸顯了 SMA 濾網在風險控制上的顯著效果。

3.  **`debugging_journey_summary.md`**
    *   **內容**：深入分析了在開發過程中遇到的 `-99%` 回報率問題的根本原因。
    *   **用途**：這是一份重要的除錯日誌，詳細記錄了我們如何發現並修正了回測引擎中關於「曝險模型」和「績效指標計算」的兩個核心邏輯錯誤。**強烈建議閱讀**此文件，以理解本次研究不僅僅是策略開發，更是一次對整個回測框架的重大修正與強化。

## 閱讀建議

1.  **了解背景**：先閱讀 `spy_monthly_buy_hold_report.md` 和 `taifex_monthly_buy_hold_with_sma_report.md`，快速了解兩個實驗的最終績效與結論。
2.  **深入核心**：接著，務必閱讀 `debugging_journey_summary.md`，以理解我們是如何從一個災難性的錯誤結果，一步步修正並最終得到這兩份可靠報告的。這份文件解釋了為什麼最終的結果是可信的。
3.  **總結**：綜合所有文件，您可以得出結論：我們不僅完成了一次策略回測，更重要的是，我們建立了一個更可靠、更準確的回測環境，為未來的策略研究奠定了堅實的基礎。
