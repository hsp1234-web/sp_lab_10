## 📋 實施總覽

### 🎯 核心目標
建立一個結合台灣期貨配對交易與選擇權保護的本金保護策略，實現：
- **每月最大回撤 < 5%**
- **季度正報酬率 > 75%**
- **年度總報酬 > 8%**
- **本金安全優先**

### 🏗️ 策略架構
```
總資金配置：
├── 60% 現金持有 - 本金保護基礎
├── 30% 配對交易 - 台指期貨低風險套利
└── 10% 選擇權保護 - 市場極端情況保險
```

def cointegration_test(series1, series2):
    # 使用statsmodels實現Engle-Granger檢定
    from statsmodels.tsa.stattools import coint
    score, p_value, _ = coint(series1, series2)
    return score, p_value

# Z分數計算
def calculate_zscore(spread, window=60):
    mean = spread.rolling(window).mean()
    std = spread.rolling(window).std()
    return (spread - mean) / std
```

# 市場壓力指數
def market_stress_index(vix, pcr, gex):
    vix_component = min(1.0, (vix - 15) / 20)
    pcr_component = min(1.0, (1.0 - pcr) / 0.4)
    gex_component = 1.0 if gex < 0 else 0.0

    return 0.4 * vix_component + 0.4 * pcr_component + 0.2 * gex_component

# 裸賣保證金計算
def naked_put_margin(premium, out_of_money_value, A_value, B_value):
    margin = premium + max(A_value - out_of_money_value, B_value) * 1.35
    return margin
```
