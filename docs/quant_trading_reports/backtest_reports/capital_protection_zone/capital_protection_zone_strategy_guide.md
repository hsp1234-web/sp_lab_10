### 月度風險預算控制
```python
class MonthlyRiskController:
    def __init__(self):
        self.monthly_limit = 0.05  # 5%
        self.daily_limit = self.monthly_limit / 20  # 假設20交易日

    def check_daily_risk(self, current_pnl):
        """檢查每日風險是否超限"""
        if current_pnl < -self.daily_limit:
            return "強制平倉"
        return "繼續持有"
```

## 📊 市場狀態識別

### 市場壓力指數計算
```python
def calculate_market_stress_index(vix, pcr, gex):
    """計算綜合市場壓力指數"""
    # VIX貢獻 (0-1)
    vix_stress = min(1.0, max(0.0, (vix - 15) / 20))

    # PCR貢獻 (0-1)，低PCR表示恐慌
    pcr_stress = min(1.0, max(0.0, (1.0 - pcr) / 0.4))

    # GEX貢獻 (0-1)，負GEX表示波動放大
    gex_stress = 1.0 if gex < 0 else 0.0

    # 加權綜合
    total_stress = 0.4 * vix_stress + 0.4 * pcr_stress + 0.2 * gex_stress

    return total_stress
```

### 市場狀態分類
| 壓力指數 | 市場狀態 | 策略回應 |
|----------|----------|----------|
| 0.0 - 0.2 | 極度樂觀 | 現金觀望 |
| 0.2 - 0.4 | 市場平靜 | 適度參與 |
| 0.4 - 0.6 | 中等壓力 | 保守操作 |
| 0.6 - 0.8 | 高度恐慌 | 減少曝險 |
| 0.8 - 1.0 | 極端恐慌 | 完全保護 |

### 主要風險
1. **模型風險**：配對交易的共整合關係可能破裂
