# 量化交易專案報告系統

## 📊 目錄結構說明

本目錄用於系統化存放量化交易策略的各類報告和文檔，確保研究成果有條理的組織和管理。

### 📁 子目錄結構

#### 📈 `strategy_reports/` - 策略報告
存放策略設計、開發和分析相關的文檔：
- 策略說明書
- 開發計劃
- 策略指南
- 參數說明

#### 🔬 `backtest_reports/` - 回測報告
存放策略回測結果和分析：
- 回測績效報告
- 策略比較分析
- 參數優化結果
- 風險分析報告

#### ⚠️ `risk_reports/` - 風險報告
存放風險管理和分析相關文檔：
- 風險評估報告
- 壓力測試結果
- VaR分析
- 風險限額設定

#### 📊 `performance_reports/` - 績效報告
存放策略績效監控和分析：
- 月度/季度績效報告
- 基準比較分析
- 歸因分析
- 績效歸因

#### 📚 `research_papers/` - 研究論文
存放學術研究和理論文檔：
- 量化研究論文
- 市場分析報告
- 新策略研究
- 理論驗證

#### 🤝 `handover_documents/` - 交接文檔
存放專案交接和知識傳承文檔：
- 策略交接報告
- 程式碼說明
- 維護指南
- 問題排查手冊

## 📋 文件命名規範

### 日期格式
- 使用 `YYYY-MM-DD` 格式
- 範例：`2025-11-27_roro_strategy_analysis.md`

### 文件類型標識
- `_guide.md` - 使用指南
- `_report.md` - 分析報告
- `_plan.md` - 計劃文檔
- `_summary.md` - 總結文檔
- `_analysis.md` - 分析文檔

### 策略命名
- 使用全小寫英文
- 使用底線分隔
- 範例：`roro_strategy`, `chandelier_strategy`

## 🔄 工作流程

1. **研究階段**：將新研究成果放入 `research_papers/`
2. **開發階段**：將策略設計放入 `strategy_reports/`
3. **測試階段**：將回測結果放入 `backtest_reports/`
4. **驗證階段**：將風險分析放入 `risk_reports/`
5. **部署階段**：將績效報告放入 `performance_reports/`
6. **交接階段**：將完整文檔放入 `handover_documents/`
