# `docs`：專案文件目錄

本目錄 (`docs`) 用於存放所有與專案相關的說明文件、開發計畫、日誌和架構圖。

## 目錄結構

```
docs/
├── logs/                   # 開發日誌
│   ├── YYYY-MM/            # 按月份分類的日誌
│   └── README.md           # 日誌系統說明
├── PROJECT_STRUCTURE.md    # (舊) 專案結構圖
└── README.md               # (本檔案) docs 目錄的說明
```

## 文件說明

-   **`logs/`**: 存放詳細的開發日誌。每個日誌都是一個獨立的 Markdown 檔案，記錄了特定功能的開發過程、遇到的挑戰與解決方案。這對於追溯專案的演進歷史非常有價值。
-   **`PROJECT_STRUCTURE.md`**: 一份描述專案結構的文件。

透過維護這個 `docs` 目錄，我們可以確保專案的知識得以沉澱，方便新成員的加入，也讓未來的維護工作更加輕鬆。
