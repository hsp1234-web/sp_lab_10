## 🏗️ 已實現的模塊架構

### 1. 市場寬度指標模塊 (`src/market_indicators.py`)
**功能**: 量化台灣股市的整體健康狀況和參與度

**核心指標**:
- **騰落線 (A/D Line)**: 漲家數 vs 跌家數的累計值
- **漲跌家數比 (A/D Ratio)**: 漲跌家數的比率
- **市場參與度**: 市場中有多少股票在積極交易

**實現特點**:
- 使用台灣加權指數成分股數據 (台積電、聯發科等權值股)
- 簡化實現以適應台灣股市數據獲取限制
- 包含數據清理和質量檢查

### 2. 系統壓力指數模塊 (`src/pressure_index.py`)
**功能**: 整合多個宏觀指標形成綜合壓力評估

**核心輸入指標**:
- **SOFR 利率**: 短期融資成本
- **利差指標**: 10年-2年、10年-3月利差變化
- **VIX 指數**: 股票市場恐慌指數
- **MOVE 指數**: 債券市場波動率
- **經濟指標**: 工業生產、貨幣供應等

**數據來源**:
- FRED API (聯邦儲備經濟數據)
- Yahoo Finance (VIX, MOVE等)
- 自動備選方案確保數據可用性

### 3. RORO 狀態引擎 (`src/roro_engine.py`)
**功能**: 將連續指標轉換為離散的風險狀態

**狀態定義**:
```
強 Risk-On:  市場寬度健康 + 系統壓力低   → 2 (FULL_RISK_ON)
弱 Risk-On:  市場寬度一般 + 系統壓力中等 → 1 (MODERATE_RISK_ON)
中性:       市場寬度中性 + 系統壓力中等 → 0 (NEUTRAL)
弱 Risk-Off: 市場寬度轉弱 + 系統壓力升高 → -1 (MODERATE_RISK_OFF)
強 Risk-Off: 市場寬度惡化 + 系統壓力極高 → -2 (FULL_RISK_OFF)
```

**決策邏輯**:
- 9種狀態組合的完整決策矩陣
- 狀態轉換平滑處理避免過度波動
- 動態資產配置建議 (TXF/TLT/GLD)

### 4. 信號生成主程式 (`src/roro_signal_generator.py`)
**功能**: 整合所有模塊，提供完整的策略執行流程

**核心功能**:
- 統一的信號生成介面
- 回測分析框架
- 多格式報告生成 (HTML/Markdown/JSON)
- 可視化圖表創建
- 績效和風險指標計算

### 5. 信號驗證框架 (`src/signal_validator.py`)
**功能**: 全面的信號品質評估和測試

**驗證內容**:
- 信號基本統計分析
- 預測能力測試 (IC、方向準確性)
- 統計顯著性檢定
- 穩健性分析
- 時序交叉驗證
