## 摘要

本次開發工作成功實作了台灣期貨交易所選擇權年度交易行情資料的下載功能。透過分析網站的 Network 請求，確認了正確的 API endpoint 與參數格式，建立了自動化下載腳本，並成功下載了 2001-2024 年共 24 個年份的選擇權資料。

## 主要變更

### 新功能開發
- **建立選擇權下載腳本**: 在 `scripts/` 目錄下建立了 `download_taifex_options.py` 腳本
- **API 端點確認**: 透過瀏覽器開發者工具確認選擇權年度下載的 URL 為 `https://www.taifex.com.tw/cht/3/optDataDown`
- **參數格式確認**: 確認 Form Data 格式為 `down_type=2&his_year={年份}`

### 腳本功能
- **自動下載**: 支援下載 2001-2024 年所有年份的選擇權年度資料
- **進度顯示**: 顯示下載進度 `[當前/總數]` 與檔案大小
- **智能跳過**: 自動跳過已存在的檔案，避免重複下載
- **錯誤處理**: 包含重試機制與詳細錯誤訊息
- **編碼處理**: 修正 Windows 終端機的 UTF-8 編碼問題

### 資料存放
- **存放位置**: `data/taifex_options_raw/`
- **檔名格式**: `{年份}_opt.zip` (例如: `2024_opt.zip`)
- **資料範圍**: 2001-2024 年，共 24 個年份

## 技術細節

### API 資訊
- **URL**: `https://www.taifex.com.tw/cht/3/optDataDown`
- **方法**: POST
- **Content-Type**: `application/x-www-form-urlencoded`
- **參數**:
  - `down_type`: `2` (年度下載)
  - `his_year`: 年份 (2001-2024)

### 回應格式
- **Content-Type**: `application/octet-stream;charset=UTF-8`
- **Content-Disposition**: `attachment;filename={年份}_opt.zip`
- **檔案格式**: ZIP 壓縮檔
