# 開發日誌目錄

本目錄記錄 Hybrid Qlib Framework 的開發歷程。

## 日誌命名規範

格式：`YYYY-MM-DD_HH-MM_brief-description.md`

範例：`2025-11-30_04-18_initial_setup_complete.md`

## 日誌內容結構

每個日誌應包含：
- **日期與時間**：記錄時間戳（亞洲/台北時區）
- **摘要**：簡述本次開發重點
- **主要變更**：列出新增/修改的檔案與功能
- **測試結果**：記錄測試執行狀況
- **問題與解決方案**：記錄遇到的問題及解法
- **下一步計畫**：規劃後續工作

## 查詢歷史

其他 AI 工具或團隊成員可透過閱讀此目錄下的日誌，快速了解專案開發脈絡。
